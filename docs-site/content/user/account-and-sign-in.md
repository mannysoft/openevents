Your login is separate from the events you manage. One account can own several organisers, so you can run multiple brands from the same email address and password.

## Create an account

From the sign-in page, select **Create an account**, or choose **Sell tickets** on the public site.

| Field | Notes |
| --- | --- |
| Name | Your own name. It appears in the dashboard header. |
| Email | Must not already be registered. Used for sign-in and password resets. |
| Password | At least 8 characters. |
| Confirm password | Must match the password. |

Select **Create account** to sign in immediately. New accounts have no organisers yet, so you land on the **Organisers** screen with an empty state.

## Sign in

Enter your **Email** and **Password** and select **Sign in**. Tick **Remember me** to stay signed in on a personal device; leave it unticked on a shared computer.

After signing in you always land on the **Dashboard**.

### If sign-in fails

- **"These credentials do not match our records."** — the email or password is wrong. Check for a typo or use **Forgot password?**.
- **"Too many login attempts. Please try again later."** — five failed attempts in a minute for the same email address and network. Wait a minute and try again.

:::caution
Do not use a shared mailbox for an organiser account: anyone with access to that inbox can reset the password.
:::

## Reset a forgotten password

1. On the sign-in page select **Forgot password?**.
2. Enter the email address on your account and select **Email reset link**.
3. The screen confirms *Check your inbox for the reset link.* — the email can take a minute to arrive, so check spam if it does not.
4. Open the link. You will see **Choose a new password**.
5. Confirm your email, enter a new password of at least 8 characters, confirm it, and select **Reset password**.

You are returned to the sign-in page with a confirmation message. Sign in with the new password.

:::note
Reset links are single use. If you open one twice, request a fresh link from **Forgot password?**.
:::

## Sign out

Select **Sign out** in the top-right corner of any dashboard screen. Your session ends immediately.

## One login, many organisers

Each organiser you create is owned by the account that created it. The sidebar's **Organisers** screen lists every organiser you own with its event count and Stripe status. There are no separate team members or invitations — organisers are only visible to the account that owns them.

:::tip
If you run several brands, create one organiser per brand. Each one gets its own Stripe account, currency and public page, which keeps reporting clean.
:::
